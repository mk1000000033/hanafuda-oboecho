# 花札おぼえ帖

花札48枚の種類と、こいこいの役を覚えるためのWebアプリです。

- **札図鑑**: 月ごとの札・種類・覚え方・関わる役
- **役一覧**: こいこいの役と点数（文）
- **クイズ**: 月・種類・名前・役・文の10問クイズ（覚えた札を記録）
- **役チェッカー**: 取った札を選ぶと役と合計点を表示

ビルド不要の静的サイトです。`index.html` と `cards/` をそのまま公開すれば動きます。
